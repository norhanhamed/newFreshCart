# FreshCart 🛒

FreshCart is a responsive E-commerce web application built with React.js and Tailwind CSS. 
The application allows users to browse products, view product details, manage their cart, and interact with an online shopping interface.

 https://norhanhamed.github.io/newFreshCart/

 Authentication → Components → Swiper → Context API → Protected Routes

 ## ✨ Project Features

### 🔐 Authentication
- User Registration
- User Login
- Form validation
- Logout functionality

### 🧭 Navbar
- Responsive navigation bar
- Navigation between application pages
- Authentication-based navigation

### 🏠 Home Page

The Home page is divided into reusable React components:

#### 🎞️ Home Slider
- Built using the **Swiper React library**
- Responsive product/banner slider
- Autoplay and smooth transitions

#### 📂 Category Slider
- Built using the **Swiper React library**
- Displays product categories in a responsive slider

#### 🛍️ Product Card
- Reusable component for displaying product information
- Product image, title, price, and other details

### 🔑 User Context & Protected Routes
- Implemented **React Context API** for managing the authentication token
- Protected routes to restrict access to authenticated users
- Authentication state is shared across the application
